# TechStore Desktop App

Desktop-приложение для работы с БД магазина бытовой техники (режимы: гость, клиент, администратор).

## Запуск

```bash
python3 app.py
```

При первом запуске создается локальная SQLite база `techstore.db` и заполняется тестовыми данными.

## Роли и возможности

- **Гость**
  - Кнопка «Просмотр» без авторизации.
  - Просмотр категорий, товаров, карточки и заказов.
  - Поиск отключен.

- **Клиент**
  - Вход по логину и паролю.
  - Просмотр карточек и заказов.
  - Поиск по частичному совпадению названия.

- **Администратор**
  - Все возможности клиента.
  - Добавление, редактирование и удаление товаров.

## Структура интерфейса

- Окно авторизации: логин, пароль, кнопки «Войти» и «Просмотр».
- Главное окно:
  - Левая панель: список товаров.
  - Центральная часть: карточка товара (фото сверху, крупное название, характеристики).
  - Панель инструментов для администратора: Добавить / Редактировать / Удалить.
- Форма заказов: клиент, дата, количество, стоимость (цена × количество), общий итог.

## SQL для MySQL

Файл `db/schema_mysql.sql` содержит скрипт создания БД `TechStore` в MySQL с начальными данными.
